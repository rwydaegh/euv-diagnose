# EUV-Diagnose

How much does EUV reflected intensity tell us about reflected phase?

Start with mask 131 from [Stuart Sherwin’s EUV release](https://github.com/s-sherwin/EUV). The target is the relative phase between absorber and exposed multilayer at 13.5 nm and 6° from normal. Keep this to one mask family.

The absorber scan is from August 2019; the exposed multilayer scan is from June 2019. These are separate acquisitions, not repeated measurements of one quantity.
